# Codomax Module 5: DevOps, CI/CD & Monitoring

## Project Overview
This project demonstrates the basics of DevOps practices using GitHub Actions, Docker, environment configuration, and monitoring documentation.

## Tools Used
- Git and GitHub
- GitHub Actions
- Docker
- Environment variables
- Monitoring commands

## Features Implemented
- Created an automated CI workflow.
- Checked project files using GitHub Actions.
- Configured a Dockerfile for a website.
- Built a Docker image automatically through the workflow.
- Created an environment configuration example.
- Documented basic monitoring and troubleshooting commands.

## What I Learned
- GitHub repository and workflow management.
- Basics of CI/CD automation.
- Docker image building.
- Environment configuration.
- Monitoring container status and logs.

## Conclusion
This project helped me practice the fundamentals of DevOps, automation, containerization, and monitoring.
