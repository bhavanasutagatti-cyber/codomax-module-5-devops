
# Application Monitoring

## Monitoring Goals
- Check whether the website is accessible.
- Monitor Docker container status.
- Review logs when errors occur.
- Check CI/CD workflow results.

## Docker Monitoring Commands

Check running containers:
```bash
docker ps
```

View container logs:
```bash
docker logs <container_name>
```

Check container resource usage:
```bash
docker stats
```

## CI/CD Monitoring
- Open the GitHub Actions tab.
- Check whether the latest workflow succeeded.
- Review the logs if a workflow fails.

## What I Learned
I learned the basics of application monitoring, Docker container status checks, log inspection, and GitHub Actions workflow monitoring.
